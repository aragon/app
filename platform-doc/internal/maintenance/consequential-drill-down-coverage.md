## Action and dependency reconciliation

The earlier inventory remains authoritative for **A01–A22**, its 20 create/edit and 19 details Basic identities, and [the canonical content map](./basic-action-views/content-map.md). Its app revision is `f8bf9e87260190aefd7d8a0eb59f72844e6e4502`, with installed UI kit `2.11.2` despite a `2.11.3` lock. Those counts were not relabeled as a production test at U1.

The complete `apps/app/src` diff from that app revision to R1 contains only two production proposal-list components and one associated test. The production changes use the display-title fallback and remove the SPP list metadata alert; they do not alter the details destination. Action registration, editors, app normalization, imports, nested arrays, cross-chain detail callers and campaign/gauge forms are byte-identical between those revisions.

U1's shipped action renderer was inspected independently. Basic still requires a supported type or custom component; Decoded requires input data and excludes explicit Raw and native-transfer-only calls; Raw remains available. The menu exists only when multiple modes are available. Edit-mode Decoded/Raw become watch views when richer input owns their data; read-only details remain read views. Raw data is not a general error boundary for a failed Basic custom renderer. U1's target links, source-network/destination-network contexts, and full-address behavior were checked rather than inferred from the older installation.

The [member-removal](../product-opportunities/preserve-member-removal-in-basic-details.md) and [import-context](../product-opportunities/preserve-plugin-context-on-action-import.md) candidates therefore remain relevant. The [destination-transfer](../product-opportunities/keep-destination-transfers-independent-of-source-account.md) and [unsupported-destination](../product-opportunities/explain-unsupported-cross-chain-destinations.md) candidates retain their stated scope. No duplicate action census, universal Basic correctness claim, new import support or automatic malformed-context downgrade is introduced here.
