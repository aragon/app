# Aragon-deployed plugins

**Aragon-deployed plugins** have a supported user experience in the application, with setup and deployment handled by the Aragon team. The app has no self-service setup for these plugins.

## Plugin catalogue

| Name | What people can do in the app |
| --- | --- |
| [Staged Proposal Processor (SPP)](../governance/proposal.md#staged-proposals) | Create proposals and participate in a governance process with multiple stages and bodies. |
| [Gauge Voter](../governance/gauge-voting.md) | Allocate voting power across destinations called gauges. |
| [Capital Distributor](../treasury/capital-distributor.md) | Manage distribution campaigns and claim allocated tokens. |
| [Cross-Chain Controller](../governance/cross-chain-execution.md) | Compose and inspect actions for an account on another network. |
| [veLocker](../governance/velocker.md) | Lock tokens, manage locks, and delegate voting power for Token Voting. |

For requirements beyond this list, Aragon also develops and deploys custom plugins and integrations through a [services engagement](./getting-help.md#when-the-app-needs-the-aragon-team).

## Deployment

Clients [contact Aragon](https://www.aragon.org/get-assistance-form) to discuss the required setup and commercial terms. The team configures and deploys the plugin according to the agreed scope.

For SPP, Aragon handles changes to the stages and participating bodies and provides [support](./getting-help.md#product-support) and [governance advisory](./getting-help.md#governance-advisory) to help clients configure and operate the process as intended. The governance designer's [Advanced — On request](../governance/governance-designer.md#the-advanced-flow) option provides a route to contact the team about this setup.
