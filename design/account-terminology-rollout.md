# Complete the account-terminology rollout

This is a product-delivery candidate, not a change to the settled copy rule owned by [Account](../accounts/account.md).

## Opportunity

Apply the rule consistently across product copy: use **account** for the product entity, reserving **DAO** for the OSx contract, exact protocol identifiers, and explicitly token-governed use cases. The current UI still uses DAO-language in generic product contexts.

## Before ticketing

- Inventory user-facing `DAO` and `account` strings across the product.
- Classify each occurrence as product language, an intentional OSx/protocol reference, or an explicitly token-governed use case.
- Define the rollout scope and acceptance checks for replacing inconsistent copy.
