Refresh how the support assistant answers from its product knowledge. The corpus loader now leaves the base's `internal/` folder out (builder guidance, design principles, maintenance and product opportunities, excluded from user-facing content by the base's own workflow) and rewrites page links for a reader outside the wiki: a relative link into `protocol-doc/` becomes the public GitHub page of that file, any other relative link keeps its text only. The system prompt is rebuilt from the product owner's review of the first answers: one file per section (role, a routing table of what the user says and what the agent does, product answers, the ticket flow, tone, a closing reminder), about half the rules, each saying what to write with an example where the shape matters. Answers speak to the user in the second person, answer the question and stop, use plain words instead of product jargon or "features", turn a source table into sentences or a complete list, and give every link as markdown with a label. The Aragon team comes up in three situations only — something the app does not have, something the team sets up, a governance design choice — after the answer, in one sentence with the contact form, and none of the source's "paid", "no self-service" or "on request" wording reaches the user. A technical protocol question gets the high-level answer and the matching GitHub page as the OSx developer documentation; a question the documentation does not cover gets "I don't know", the facts at hand and one question about passing it on. The product is Aragon, never "Aragon App". Contracts: a message may be up to 8,000 characters (was 4,000), the same limit the widget now applies in the composer; every app-context value is one bounded line and the ticket fields have ceilings, so a hand-made request cannot push free text into the system prompt or an oversized body into Linear — the app context no longer enters the prompt at all, only the ticket.

The agent model moves from `deepseek/deepseek-v4-flash` to `deepseek/deepseek-v4.1-flash`, served by the DeepSeek host first and Together AI second instead of Fireworks, which drops v4-flash on 2026-09-25: in a ten-scenario sweep the new model kept every prose rule the old one broke and answered in 4–6.5 s instead of 8–15 s. Search excerpts grow from 1,500 to 2,500 characters so a reference table reaches the model whole.
